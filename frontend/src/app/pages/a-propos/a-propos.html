À propos du projet

InfraScan Pro est une application de gestion d'infrastructures routières développée pour permettre aux inspecteurs de suivre l'état de santé structurel de ponts, viaducs et tunnels en temps réel.

Le projet couvre l'ensemble d'un cycle de développement full-stack réel : conception de la base de données relationnelle, API REST sécurisée en .NET, interface Angular réactive, et déploiement cloud automatisé sur Azure via un pipeline CI/CD.
